# 🎓 Zyntra - نظام إدارة الحضانات والمدارس

منصة إدارية متكاملة لإدارة الحضانات ورياض الأطفال (React + TypeScript)، مبنية بأحدث تقنيات الويب لتوفير تجربة استخدام سريعة وسلسة لفريق الإدارة.

## ✨ المميزات الرئيسية

### 📊 لوحة تحكم شاملة
عرض سريع لأهم المؤشرات والأنشطة اليومية في مكان واحد.

### 🏢 إدارة البيانات الأساسية
الفروع، الأقسام، الفصول، والمستويات الدراسية — إضافة وتعديل وأرشفة بسهولة.

### 🎓 إدارة الطلاب
تسجيل الطلاب، متابعة بياناتهم، الإخوة المسجلين، أعياد الميلاد، وإجراءات التخريج.

### 👥 إدارة الموظفين
بيانات المعلمين والعاملين، مع إمكانية المتابعة والتحديث المستمر.

### ✅ العمليات اليومية
تسجيل الحضور والغياب والانصراف بشكل لحظي، مع دعم التسجيل الجماعي لتوفير الوقت.

### 🏆 تقييم يومي تفاعلي
نظام تقييم سهل الاستخدام لمتابعة أداء الطلاب وتكريم المتميزين يوميًا.

### 💰 الإدارة المالية
متابعة الاشتراكات وتسجيل الدفعات وحركات الخزينة بدقة وشفافية.

### 📁 الأرشفة والسجلات
أرشيف كامل للرسائل، وسجل موثّق لعمليات الدخول والخروج.

### 🔐 إدارة المستخدمين والصلاحيات
نظام أدوار (Roles) يضمن وصول كل مستخدم للصلاحيات المناسبة له فقط، مع حماية كاملة للإعدادات الحساسة.

### 🌐 تصميم عربي بالكامل
واجهة RTL متكاملة، خط عربي واضح ومريح، وتجربة استخدام مصممة خصيصًا للمستخدم العربي.
